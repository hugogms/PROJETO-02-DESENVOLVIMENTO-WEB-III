## 🎯 Descrição do Projeto
Este projeto é um portal web interativo desenvolvido para apresentar as disciplinas do 3º semestre do curso da FATEC.
A plataforma oferece navegação intuitiva entre as matérias, detalhando conteúdos acadêmicos e contando com recursos visuais como um modal para ampliação de imagens.

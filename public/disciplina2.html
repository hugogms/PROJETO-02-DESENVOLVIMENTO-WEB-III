Técnicas de Programação II

Sigla: TPII

Professor Responsável: Vinicius Heltai Pacheco

Descrição da Disciplina

Esta matéria aprofunda os conceitos do paradigma de Programação Orientada a Objetos (POO). Trabalha com a aplicação de padrões de projeto (Design Patterns), tratamento avançado de exceções e persistência de dados para a criação de sistemas modulares, escaláveis e de fácil manutenção.

Principais Assuntos Trabalhados

  • Programação Orientada a Objetos Avançada
  • Padrões de Projeto (Design Patterns)
  • Tratamento de Exceções e Persistência
